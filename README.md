# เมนูชุมชน (Community Menu Planner)

โปรแกรมช่วยร้านอาหารตอบ 3 คำถามทุกวัน:
**วันนี้ทำเมนูอะไรดี? ของในร้านพอไหม? ต้องซื้อจากเกษตรกรเพิ่มเท่าไหร่?**

เป็นโปรแกรมบนคอมพิวเตอร์ (Windows) เขียนด้วย Python ทั้งหมด
ข้อมูลเก็บในเครื่อง ใช้ AI ของ Google (Gemini) ช่วยแนะนำเมนู



---

## โปรแกรมทำอะไรได้บ้าง

| แท็บ | ใช้ทำอะไร |
|---|---|
| หน้าหลัก | ดูทันทีว่าของอะไรใกล้หมด อะไรใกล้ถึงวันควรใช้ก่อน มีของสั่งไว้รอรับไหม |
| คลังวัตถุดิบ | รับของเข้า เบิกของไปใช้ จดของเสีย — แยกเป็นล็อต เพื่อใช้ของเก่าก่อน |
| สูตรอาหาร | จดว่าแต่ละเมนู 1 จานใช้อะไรเท่าไหร่ |
| ข้อมูลชุมชน | จดว่าเกษตรกรรายไหนขายอะไร ราคาเท่าไหร่ ส่งได้วันไหน |
| แผนเมนูและ AI | ให้ AI แนะนำเมนู → เลือกเมนูและจำนวนจาน → ดูว่าต้องซื้ออะไรเพิ่ม กี่บาท |
| การจัดซื้อ | ออกใบสั่งซื้อ และกดรับของเมื่อของมาถึง (ของเข้าคลังให้เอง) |
| รายงาน | ดูยอดซื้อจากเกษตรกร ยอดใช้ของ และของเสีย ตามช่วงวันที่ |

## วิธีเปิดใช้

### แบบง่ายสุด: ใช้ไฟล์ .exe
ดับเบิลคลิก `CommunityMenu.exe` ได้เลย ไม่ต้องติดตั้งอะไร

- ควรวางไฟล์ไว้ในโฟลเดอร์ของมันเอง เช่น `เอกสาร\CommunityMenu\`
  เพราะโปรแกรมจะสร้างไฟล์เก็บข้อมูล `community_menu.db` ไว้ข้าง ๆ
- ถ้า Windows เตือน "Windows protected your PC" ให้กด **More info → Run anyway**
  (เตือนเพราะไฟล์ไม่ได้ซื้อใบรับรองจาก Microsoft ไม่ใช่ไวรัส)
- **สำรองข้อมูล** = ก๊อปไฟล์ `community_menu.db` เก็บไว้
- **เริ่มใหม่ด้วยข้อมูลสมมติ** = ปิดโปรแกรม ลบไฟล์ `community_menu.db` แล้วเปิดใหม่

### แบบรันจากโค้ด (สำหรับคนที่จะแก้โปรแกรม)
1. ติดตั้ง Python 3.10 ขึ้นไป จาก https://www.python.org
   (ตอนติดตั้งให้ติ๊กช่อง **Add python.exe to PATH**)
2. เปิด Command Prompt ในโฟลเดอร์นี้ แล้วพิมพ์
   ```
   pip install -r requirements.txt
   ```
3. เปิดโปรแกรม
   ```
   python main.py
   ```

คำสั่งอื่นที่มีประโยชน์:
```
python db.py            ล้างข้อมูลทั้งหมด แล้วใส่ข้อมูลสมมติใหม่ (ใช้ก่อนนำเสนอ)
python -m unittest -v   ตรวจว่าโปรแกรมยังคิดเลขถูก (ขึ้น OK = ผ่าน)
```

## ลองใช้ตามลำดับนี้ (ตัวอย่าง: ฟักทองผัดไข่ 30 จาน)

1. **คลังวัตถุดิบ** → คลิกฟักทอง จะเห็นว่ามี 2 กก. และใกล้ถึงวันควรใช้ก่อน
2. **ข้อมูลชุมชน** → เห็นเกษตรกรขายฟักทอง 30 บาท/กก. ไข่ 5 บาท/ฟอง
3. **แผนเมนูและ AI** → ใส่งบ 100 บาท, 30 จาน → กด **ให้ AI แนะนำเมนู**
4. เลือกฟักทองผัดไข่ 30 จาน → โปรแกรมบอกว่าต้องซื้อฟักทอง 1 กก. + ไข่ 10 ฟอง **รวม 80 บาท**
5. กด **ยืนยันแผน + สร้างคำสั่งซื้อ** → ไปแท็บ **การจัดซื้อ** → กด **บันทึกรับสินค้า** → ของในคลังเพิ่มขึ้น
6. กลับแท็บแผนเมนู → กด **ยืนยันเบิกวัตถุดิบตามแผน** → เปิดแท็บ **รายงาน** ดูสรุป

ทุกครั้งที่แก้โค้ด ต้องสร้าง .exe ใหม่ ไม่งั้น .exe ยังเป็นเวอร์ชันเก่า


## ไฟล์ในโฟลเดอร์นี้มีอะไรบ้าง

| ไฟล์ | หน้าที่ (พูดง่าย ๆ) |
|---|---|
| `main.py` | ตัวเปิดโปรแกรม สร้างหน้าต่างและแท็บทั้ง 7 |
| `screens/` | หน้าจอแต่ละแท็บ แยกไฟล์ละหน้า |
| `logic.py` | "สมอง" ของโปรแกรม คิดเลข ตรวจว่าทำได้ไหม จัดการคลังและใบสั่งซื้อ |
| `db.py` | สร้างที่เก็บข้อมูล และใส่ข้อมูลสมมติตอนเปิดครั้งแรก |
| `ai_helper.py` | คุยกับ AI และตรวจคำตอบของ AI |
| `test_logic.py` | ชุดตรวจว่าโปรแกรมคิดถูก (15 ข้อ) |
| `CODE_GUIDE.md` | อธิบายโค้ดแบบภาษาคน |
